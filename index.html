qrem CLI

A frictionless, offline task scheduler built for the terminal.

Download for Windows (v1.0)

Why qrem?

Designed for developers who live in the terminal. No electron bloat, no mandatory cloud accounts, and no UI to distract you. Drop a task into the database from your command line, and let your operating system handle the rest.

Zero Overhead

Compiled natively in C++ with an embedded SQLite database. It consumes absolutely zero RAM or CPU until the exact minute a notification fires.

100% Offline

Your schedule stays entirely on your local machine. No external servers or API calls.

Native Alerts

Integrates directly with Windows Toast Notifications to deliver unmissable desktop alerts.

Fast, Intuitive Commands

Add reminders for upcoming coding contests, daily habits, or one-off tasks without breaking your workflow. 

# Schedule a one-time reminder
qrem add "Codeforces Div 2 Round" "2026-09-28 20:30" one-time

# Build a daily habit
qrem add "Complete 1 React/Vue module" "2026-09-29 10:00" daily

# View your upcoming schedule
qrem list

# Remove a cancelled task
qrem remove 1

Instant Installation

The distribution package comes with an automated installation script. Simply extract the ZIP file and run install.bat. It automatically registers the invisible background scheduler, sets up your PATH variables, and removes security blocks.
